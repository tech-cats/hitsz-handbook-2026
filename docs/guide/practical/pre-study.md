# 先修、英语分级考、大一立项

26级把C语言加入了先修清单，而且看起来似乎课程名也改叫**计算思维与人工智能**了，这在之前事实上是非计算机类上的Python课的名字。

先修的大意是，在学期开始之前的假期提前学习某门/某些课程，然后考试，一旦考试达到某些要求。

我们印象最深刻的就是暑假的微积分先修和寒假的微积分先修，因为他们在25级保持了0.00%的高通过率。关键是还是有人去参加。所以这里真正的问题首先是解开一个谜：为什么总是有人相信先修可以让人比高下？

请回到高考和高中数竞的区分，可以注意到高中数竞一定要给比高考长的多的时间，因为数竞的题更“难”。再比如历史上的数学家经常要用一夜、好几天、几个月去思考一个问题。既然这些都是常识，那么接下来自然可以推出，如果老师凭个人喜好往接近高数考试时间的卷子里塞了竞赛难度的试题，那么这套题客观上就是一套考察函数严重错位的题。这样测出来的到底是一种过拟合的能力，还是其他的数学建模思维、逻辑严谨性？老师的想法倒是很有可能挺直白的：制造一场下马威，避免新生飘飘然。先修mooc就远比实际的先修题范围窄、易上手、题型标准且简单。所以如果愿意参加先修，应该把它当成一场旅行，而不是试炼场。

所以，为什么新生一定要认为，数学这个词背后代表一个统一可比较高下的机制？这一点甚至在英语分级考也显现了出来。

英语分级考也很简单，开学军训期间考一套雅思难度的试题，据此分出A/B/C班，比例是1：2：1（这是一个固定比例）
