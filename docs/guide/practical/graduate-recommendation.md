# 综测与保研

首先要记住的第一件事情是，哈深的课程可以分为**考试课**和**考察课**两大类，他们的区分标准不是有没有考试，而是看是否计入百分制的**核心课程学分绩**（哈深通常不说绩点）。至于到底怎么看一门课到底对应考试课还是考察课，最优解是直接去教务网站上查询。

平均学分绩，也就是我们在手机本研app看到那个成绩，它的计算方式是：$\displaystyle \text{平均学分绩}=\frac{\sum \text{考试课程学分绩}}{\sum \text{考试课程学分}} - \frac{\sum \text{考查课不及格学分数}}{\text{计算平均学分绩的学期数}}$

学校的保研看起来还是有确定性的。

……

值得注意的是，保研升学从来不是一个连续步骤。推免的全称一直都是“推荐优秀应届本科毕业生免试攻读硕士学位研究生”，也就是免去初试，不是说“获得资格”之后，就自动滑入“导师接收”那一步。对哈深而言，前者是学分绩基础+竞赛加分的天堂，但是后者却依赖政策。这意味着，如果政策滑向收窄学硕、专硕的名额，就有一批学生要滑向工程硕博、保外（甚至不一定是上保），甚至可能面临无人接受的窘境。《专业学位研究生教育发展方案》要求专硕占比到三分之二，复旦物理系2026年起停招学硕；更直接的是本部2025年的推免通知——"学术学位硕士原则上全部纳入硕博贯通培养"。况且哈深所谓的本校保底本来就不是全国大学的常态。
而且，研究生与学术的联系远没有那么深。任何读者就可以查查哈深研究生的出路，这些都是公开可查的信息。这里最大的问题根本不是要不要想通要不要保研，这个还是规划人生性质的，真正的问题是时代在剧变，而这种好好学生的路径很可能成为牺牲品，除非他本身不只是好好学生而已。不应该赌注读研，也不应该埋头苦学不谙世事，应该多接触新事物。大量的路径规划都可以直接被认为是无效的，甚至这句话还是太保守了，坏路径规划可以锁死未来。
