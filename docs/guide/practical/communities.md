# 社群与平台、官方民间与…

哈深的社群生态是特殊的。在校内存在一个未被官方定义、也未完全被外界察觉的“平行生态”，一套由学生自发构建的“无名系统”。它们混杂但较为有序。

下面是一些QQ群聊的介绍：

**水群**会在招生季以非官方的新生群面目出现，后续改名为水群。以日常闲聊为主，偶有压抑和发癫环节。唯一要注意的是，开学季水群会混入骗子，拉学生进什么资料群、通知群、校园墙群，均为诈骗。

**自救群**是哈深的学业互助群，半实名，进群时核对学号姓名。AI时代后，大家很少问学业问题了，但是这里依旧是交换学习资料的平台。因此，哈深的一大特色就是，不存在大规模学习资料的买卖，也不能相信倒卖资料的二道贩子。任何哈深学子都应该坚决反对资料倒卖。

**跳蚤市场**是哈深的**多个QQ群**，从2016级一路传承下来，用于二手交易。但是因为成员复杂，群聊常常滑向与二手无关的话题。再时间久了，这种群便成为了哈深QQ群聊里的都市传说，偶尔会有人提及。

**兴趣群**是哈深学子自发组建的群聊，以某一个话题为主。我们的兴趣群名册允许我们随时加入某一个兴趣群，也不用过分担心目标群聊是否不欢迎自己。

此外，社团、战队也会建立自己的群聊，官方的通知群、课程群也通常依托QQ，但这是题外话。
