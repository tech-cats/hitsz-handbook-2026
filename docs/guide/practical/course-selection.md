# 选课与学分

和高中的学习规则不一样，至少原则上，大学的课是需要自己选的。比如说大一、大二要上的体育课就不再是初高中那种以**行政班**为单位的统一课堂模式，而是可以自己选乒乓球、羽毛球、足球、游泳以及其他体育类课程。

一次选课的过程，我们可以分为**正选**、**补选**两个部分，以及在补选之后还有一个特殊补选的机会。

至于什么时候选课，以官方通知为准。

哈工深的学分机制并非差强人意，实际上就是让人不满，而且快速变化。2025级除了必修的学分之外，其他的分门别类的学分机制如下，和能否毕业高度相关：

**创新学分与社会实践学分。** 要求二者和≥6，创新学分≥4，社会实践学分≥1。创新学分来源于创新类课程/竞赛获奖，社会实践学分来自于志愿时（1学分=50志愿时）或者某些大的社会实践活动（比如寒招，也就是回母校宣传自己的学校）。在25级，公认的经验是找到容易获奖的竞赛+参加寒招。但是寒招活动未来是否会算学分呢，谁又知道呢？这个非常看政策，参加活动的人一定要问清。

这里甚至还有个坑，25级电气的培养方案写的是创新学分≥5。虽然实践中，大家心照不宣都是去搞5创新学分，但这个确实有点考验人的视力了。

创新学分、社会实践学分这种需要申请认定的学分需要等大二分学部学院后才能去申请。例如，如果你大一寒假参加了寒招，这个活动并不会自动成为你的学分，需要等。

**文理通识学分。** 25级（某个特殊班型除外）要求文理通识学分≥8，其中某些线下课程可能会计入这一类学分。除了这个大要求，还有三类小要求：四史至少一门。（教务平台上有些会写≥0.5，有些≥1，实操和选一门差不多。）、全英≥2学分、美育≥2学分。

还有一个MOOC机制。每学期都可以选文理通识的MOOC，在“智慧树”或者“中国大学MOOC”两个平台去上课。MOOC一共只能认定2学分，但是却可以重复满足上述三类学分的要求。比如如果我在MOOC选了一门2学分全英、一门2学分四史、一门2学分美育，那我可以视为满足了小三类要求，并且获得了2文理通识学分，线下还需要6分任意类的文理通识学分。MOOC是一个挺巧妙的绕开方法。但是受制于政策。用什么方法去降低某些压力要综合考虑政策、个人资源、外部条件等影响。

**跨专业学分。事实上，26级已经删去了这一门学分，不过本文保留了这一项。** 要求修满≥10学分。【AI特色院士班的同学来自于本部，没有这个安排，但是他们却有240学时的基础项目实践和另一门400学时的课，不必多言。】

这个时候又有一种规则。哈工深的一部分专业是“1+1+X”模式，大二是“大类课+轨道课（自选）”。轨道课按专业去分轨道，如果选了其他专业的轨道课，会被认定为跨专业学分。于是25级就出现了通信自己的轨道课被计算机、电气同学大量涌入的情况。通信确实必修自己的课，但计算机电气同学也会说：“我们也想快点修完跨专业，用力地活下去。”

如果是大二、大三、大四三年修完，那确实看起来很宽松──但是大三实习、大四秋招，还有同学可能选择竞赛。而且不管是不是分摊，这个跨专业的安排本身就是挤占时间。实践中考虑外专业的老师很少。什么经济学原理，那真的是直接按本专业的流程来，规格严格。

跨专业课程是全校学生（除了新大一）都要去抢的，非常混沌，甚至可能有买卖课程资格的灰色地带。

辅修这些，如果只是为了毕业，不需要考虑。确实也有辅修学分->跨专业学分的路子，但我没有详细了解过。

可以说，分门别类的学分并没有带来某种多样化的校园生活，反而加重了学生的负担。学生要和学分政策、选课平台以及自己的时间勾心斗角。

我们甚至希望这些东西不要上秤──就好像创新学分，如果真的收严，要求人均创新，那最终的结果是所有人都会表演创新，而那种实现自己idea的闪光反而不复存在了。

未来可能会发生变化，但大概的地基就在这里，除非学分制本身被改变了。
