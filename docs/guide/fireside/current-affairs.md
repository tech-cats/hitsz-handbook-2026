# 时·时局之问

## 前言

为了写作这本新《生存手册》，我这几天一直在研读《上海交通大学生存手册》。它的结构是立志篇->访谈录->具体事项。我们把结构倒置了，高度时效性的校园事务放到了最前面，后面再来讨论一些议题。

上交手册的立志篇希望我们明白一件事：

有志者反而是那些不再相信旧的立大志的人。

## 从上行期到后疫情时代

也就是说，真正的问题域已经悄悄迁移了。结果到最后，那种几十年如一日的稳定也是一种幻觉。我认为任何基于现行形势，尤其是新大学生的人生规划有效──这些规划往往寿命活不过大一的三个月。

我们应该终止过去那种自诩精英的看法。在当今这种情况下，保持定力。
