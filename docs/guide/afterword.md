# 在最后之后

一本手册失去他的基础有很多原因，

我们也没有那一代人那样有热情，那样相信自己了。尽管我知道或许只是那一个时代的缩影，也不能代表所有人等等，但我确实相信他们的文本确实有他们时代的精神。

也许我们不该谈说手册是针对所有人的。手册事实上一定是特殊的，最后靠着特殊的事情去讲出一些普遍的困境。如果直接说普遍，那又变成空中楼阁了。首先，即使是在哈深内部，我们的手册的很多章节也并不对哈深的所有学子有效。哈深的很多求学者可以从来不接触网络社群，不接触AI的议题，或者觉得那些都是噪音。更别说是对全国大学生了，我们也没有时间去实际调查全国大学生的生存现状，但我们确实知道自己周边面对的矛盾，要做的就是记录历史、总结经验，这样普遍的道理自己会跳出来。可能未来我们不再需要一个所谓的手册了。当下的手册更多也是过渡性质，应该强调临时性和时效性，而不是捧成圣经，不然手册就失败了。如果我们真的想改变局面，那么成功的标准就应该是，后面的人不再理解我们想做的一些事情的意义，用一个不恰当的比喻，就好像我的一个朋友完全不理解为什么封建领主和小农只屯粮而不想办法做资本增值一样。（一个时代觉得天经地义的事，后来的人可能完全无法理解，因为生活的逻辑已经变了。）

也许我们不该谈理想，因为对今天的大学生来说理想太远了；也不该谈所谓的“现实”，因为这个词已经被各路犬儒主义者、精致利己者滥用了，快腌入味了。我们先毕业、糊口，然后看看能做到什么。在这一点上我们985的同学和普通人一样，大家的伦理抉择也都是真实的。而且理想早就藏在种种事情之中了。
